# 08 | 练习：渐进式披露原理

## 🎯 练习目标

- 理解 Level 1/2/3 的加载时机
- 能根据场景决定哪些内容放在哪个 Level
- 能设计合理的渐进式披露结构

---

## 📋 练习要求

### 基础任务（必做）

**1. 判断以下内容应该放在哪个 Level：**

| 内容 | 应该在哪个 Level？ |
|------|-----------------|
| `name: code-review` | |
| `description: 代码审查 SOP...` | |
| 详细的安全检查清单（500字） | |
| `scripts/run-tests.sh` 执行脚本 | |
| `references/security-checklist.md` | |
| 输出报告的模板格式 | |
| 触发关键词列表 | |

**2. 设计一个 Skill 的渐进式披露结构：**

场景：code-review Skill

- 包含详细的安全检查清单（很长）
- 包含性能检查清单
- 包含一个生成报告的脚本

请设计目录结构，说明每个文件放在哪个 Level。

**3. 错误分析：**

```yaml
---
name: code-review
description: 代码审查 SOP

# Security Checklist
1. SQL 注入检查
2. XSS 检查
3. 硬编码密钥检查
... (100+ 行)

# Performance Checklist
1. N+1 查询检查
2. 循环优化检查
... (100+ 行)
---
```

这个 SKILL.md 有什么问题？如何改进？

### 进阶任务（选做）

**分析一个真实 Skill 的渐进式披露设计：**

访问 agentskills.io，找一个公开的 Skill，分析它的 Level 1/2/3 是如何设计的。
