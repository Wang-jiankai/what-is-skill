# 01 | 基础练习：理解 Agent Skill

## 🎯 练习目标

- 理解 Agent Skill 解决的核心问题
- 区分 Skill 和 MCP 的本质不同
- 理解渐进式披露的原理

---

## 📋 练习要求

### 基础任务（必做）

**思考并回答以下问题：**

1. **问题场景**：你团队里的代码审查，每次 AI 审查的结果都不一样——有时审得细，有时跳过了安全检查。

   为什么？Agent Skill 能怎么解决这个问题？

2. **区分 Skill 和 MCP**：

   填写下表，说明每种情况该用 MCP 还是 Skill：

   | 场景 | 该用哪个 | 理由 |
   |------|---------|------|
   | AI 需要读写本地文件 | | |
   | AI 需要按"代码规范"审查 | | |
   | AI 需要调用 GitHub API | | |
   | AI 需要按"SOP"写测试报告 | | |
   | AI 需要查询数据库 | | |

3. **渐进式披露**：为什么 Skill 要分 Level 1/2/3？直接全部加载不是更简单？

### 进阶任务（选做）

**设计你的第一个 Skill 构思**（不需要写完整 SKILL.md，只需要想清楚）：

- 你在工作中最重复的一件事是什么？
- 每次做这件事，标准流程是什么？
- 如果把这件事写成 Skill，会包含哪些内容？
