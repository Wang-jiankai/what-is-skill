# Meeting Notes SOP

## When to Use
当用户要求整理会议内容、生成 meeting notes、或提交会议记录时使用。

**触发关键词**：meeting notes、会议纪要、会议记录、整理会议、summary

**不适用**：
- 用户只是想讨论问题（不需要输出结构化纪要）
- 用户要求做会议记录而非整理

## Prerequisites
- 获取会议内容（文字记录、录音转写、或用户口述）
- 确认会议主题和参与人员（如有）

## Steps

### Step 1：识别会议要素
提取并确认以下信息：
- **会议主题**：这次会议讨论的核心议题是什么？
- **参与人员**：有哪些人参加？（如有）
- **会议时间**：何时召开？（如有）

### Step 2：提取关键决策
识别会议中做出的具体决定：
- 做了哪些决定？
- 每个决定的原因是什么？
- 有没有未达成共识的问题？

### Step 3：提取行动项
识别会议中产生的待办任务：
- 谁负责什么？
- 截止时间是什么？
- 有没有需要跟进的决定？

### Step 4：识别遗留问题
识别悬而未决、需要后续讨论的问题：
- 哪些问题没有结论？
- 需要谁在何时跟进？

## Output Format

会议纪要必须包含以下部分：

```
## 📋 会议信息
- **主题**：[会议主题]
- **时间**：[日期时间]
- **参与人**：[人员列表]

## 🎯 会议决策

### 决策 1：[简要描述]
- **内容**：[具体决定]
- **原因**：[做此决定的原因，如有]

### 决策 2：...

## 📌 行动项

| 任务 | 负责人 | 截止时间 |
|------|--------|---------|
| [任务描述] | [姓名] | [日期] |

## ❓ 遗留问题

- [问题描述] — 需要 [谁] 跟进
```

```
