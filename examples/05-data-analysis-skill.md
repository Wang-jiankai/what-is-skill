# Data Analysis SOP

## When to Use
当用户提供数据并要求分析、生成报告、或提取洞察时使用。

**触发关键词**：分析、数据分析、data analysis、report、洞察

**不适用**：
- 用户只想可视化数据（用 data-viz Skill）
- 用户要求机器学习建模（用 ml-model Skill）

## Prerequisites
- 获取数据源（文件路径、数据库连接、或直接提供的数据）
- 确认分析目标（用户想通过数据回答什么问题？）

## Analysis Steps

### Step 1：理解数据
- **数据概况**：多少行、多少列、数据类型
- **字段含义**：每个字段代表什么
- **数据质量**：是否有缺失值、异常值、重复行

### Step 2：描述性统计
对所有数值字段计算：
- **集中趋势**：均值、中位数
- **离散程度**：标准差、最大/最小值
- **分布**：直方图或频率分布

对所有分类型字段计算：
- **类别数**：有多少个不同值
- **高频值**：最常见的 5 个值及其频率

### Step 3：相关性分析
- 数值字段之间的相关性（皮尔逊相关系数）
- 关键变量与目标变量的关系

### Step 4：发现与洞察
基于分析结果，提炼：
- **主要发现**（3-5 条，用数据支撑）
- **异常点**（如果有）
- **建议**（基于数据能给出什么行动建议）

## Output Format

分析报告必须包含：

```
## 📊 数据分析报告

### 1. 数据概况
- **记录数**：[X 行]
- **字段数**：[X 列]
- **关键字段**：[列出最重要的字段]

### 2. 数据质量
| 字段 | 缺失率 | 异常值 | 备注 |
|------|--------|--------|------|

### 3. 描述性统计
| 字段 | 均值 | 中位数 | 标准差 | 范围 |
|------|------|--------|--------|------|

### 4. 主要发现
1. **[发现 1]**：[数据支撑]
2. **[发现 2]**：[数据支撑]
3. **[发现 3]**：[数据支撑]

### 5. 建议
1. **[建议 1]**：基于 [发现 X]
2. **[建议 2]**：基于 [发现 Y]

### 6. 后续分析建议
（如有更深入分析的可能）
```

## Examples

### Example 1：触发 Skill
```
用户：帮我分析一下这个 CSV 文件，看看用户留存有什么问题
AI：[加载 data-analysis Skill]
    → Step 1：理解数据（发现是用户行为日志）
    → Step 2：统计（计算次日/7日/30日留存率）
    → Step 3：相关性（留存与哪些行为相关）
    → Step 4：发现（第 7 天留存骤降是关键问题）
```

### Example 2：直接提供数据
```
用户：分析：[粘贴数据表格]
AI：[加载 data-analysis Skill] → 按 SOP 执行分析
```
